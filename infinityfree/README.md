# InfinityFree Deployment

This folder is generated by the InfinityFree build script.

## What it contains

- A production build of the React frontend
- An `.htaccess` file for React Router SPA routes

## Important

- InfinityFree free hosting does not support Node.js / Express.
- The frontend can be deployed there as a static site.
- For full file-processing features, point `VITE_API_URL` to an external backend that supports Node.js or PHP, then rebuild.
